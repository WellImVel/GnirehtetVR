# GnirehtetVR
I am not the original publisher; I simply created a more stable version for PC VR gaming, which allows for the addition of several extra devices without losing the connection to the headset.

When comparing performance—using my software versus the raw, out-of-the-box version—you’ll see your frame rate double; in my own testing, it jumped from 10 FPS to 30 FPS.

Furthermore, there’s no longer any need to constantly restart the application or reinstall it on the headset. My software performs ongoing checks, and if an error occurs, it silently restarts the server without breaking your immersion in the gameplay.
